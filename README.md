# 美国高校排名 Top 60

U.S. News 2026 全美综合大学排名 + 计算机专业排名可视化页面。

**在线地址**：https://ssuper1.github.io/us-universities-top60/

## 这是什么

一个**单文件、零依赖**的 HTML 页面（数据、样式、脚本全部内联），双击即可在浏览器打开，不需要构建、不需要联网安装任何东西。

## 功能

- **双视图切换**：综合排名（前 60，含并列实际覆盖到第 59 名、共 63 所）／计算机专业排名（前 50，按并列结构覆盖到第 46 名、共 50 所；**研究生榜**，适合硕博申请）
- **计算机排名互通**：综合视图附「计算机排名」列，计算机视图反过来附「综合排名」列，两榜可对照
- **筛选**：按校名搜索、按公立／私立／藤校过滤、按名次区间筛选
- **名次区间三种操作方式**：直接填起止数字、点 1–10 / 11–30 / 31–60 预设、拖动双柄滑轨（每 10 名一档，也可在轨道上单击直接跳档）
- **地图定位**：所在州显示中文全称，点击弹出美国地图浮层标出学校大致位置
- **一键搜索**：每校配一个 Bing 搜索（新标签页打开）
- **校名可点，按名次分两种行为**
  - 综合排名 **前 30** → 跳转该校**官网首页**（外观与纯文本一致，不带下划线以作区分）
  - 综合排名 **第 30 名及以后** → 跳转该校**研究生入学要求页**（带下划线 + ↗ 标记）
- **回到顶部**：小按钮，靠边悬浮、不遮挡正文

## 数据来源与可信度

**榜单来源**：U.S. News & World Report

- 《2026 Best National Universities》全美最佳综合大学排名，2025 年 9 月发布
- 《2026 Best Computer Science Schools》最佳**研究生**计算机科学排名，2026 年 4 月发布（适合硕博申请；本科 CS 榜不在本页提供）

**需要说明的是**：页面中的名次是**依据上述已公布榜单整理、并经多来源交叉核对**得到的，**并非从 U.S. News 官网直接采集**。原因是官方表格页只公开前 10 名，部分指标位于 College Compass 付费墙之后。

因此数据可信度分三档：

| 区间 | 可信度 | 说明 |
| --- | --- | --- |
| 综合排名 1–40 | 高 | 官方页面逐个核对，其余多来源互证 |
| 综合排名 41–60 | 中 | 官方表格只渲染前 10，此段依赖多个第三方整理表互相印证，媒体之间偶有 1 名出入 |
| 研究生 CS 榜 34 / 38 / 43 / 46 名四档 | 高 | jingsailian 与 gaotu 两份独立整理表完全一致 + 波士顿大学官方新闻稿直接确认第 46 档 + 名次守恒规律（累计校数+1=下一档）逐档验算通过 |

- U.S. News 研究生 CS 榜的公开名次是**跳号**的（第 1 名 3 所 → 第 4 名 1 所 → 第 7 名 3 所 → 第 12 名 3 所 → 第 15 名 4 所 → 第 21 名 4 所 → 第 27 名 7 所 → 第 34 名 4 所 → 第 38 名 5 所 → 第 43 名 3 所 → 第 46 名 5 所 → 下一档直接跳到第 51 名），所以"前 50"实际覆盖到第 46 名、共 50 所，第 47–50 名在官方榜上是空号
- 乔治华盛顿大学的研究生入学要求页整站被 Cloudflare 拦截，脚本与浏览器均无法验证页面内容，仅确认域名有效
- 校名链接指向的入学要求页面采集并核验于 2026-09-12；招生要求每年更新，申请前请以官网当年页面为准

**免责声明**：排名数据版权归 U.S. News & World Report 所有，本项目仅作学习与个人参考之用，不得用于商业用途。榜单每年变动，用作申请决策前请以官方最新发布为准。

## 使用

```
双击 us-universities-top60-2026.html
```

或起一个本地静态服务：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/us-universities-top60-2026.html`。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 地图使用 d3 v7 + topojson v3（CDN 加载）+ us-atlas 州界拓扑，按 FIPS 码匹配高亮
- 双柄滑轨基于两个原生 `input[type=range]` 叠加实现，两个手柄共用同一把刻度，支持点击跳档与按住拖动
